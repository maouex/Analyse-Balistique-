# Analyse Balistique

## Setup

```bash
cd analyse-balistique-react && npm install
```

## Build

```bash
cd analyse-balistique-react && npm run build
```

## Lint

```bash
cd analyse-balistique-react && npm run lint
```

## Project Structure

- `analyse-balistique-react/` - Application React/TypeScript (Vite + React 19 + Three.js)
- `analyse-balistique.html` - Version HTML monolithique legacy (119 Ko)
